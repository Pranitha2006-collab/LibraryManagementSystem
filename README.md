# Library Management System

## Description

The Library Management System is a console-based Java application that helps manage books in a library. Users can add new books, display all available books, search for books by title, and remove books from the collection.

This project demonstrates the use of Object-Oriented Programming (OOP), ArrayList collections, and basic CRUD (Create, Read, Update, Delete) operations in Java.

## Features

* Add new books to the library
* Display all books
* Search for a book by title
* Remove a book from the library
* Menu-driven console interface
* Dynamic book storage using ArrayList

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Scanner Class
* CRUD Operations
